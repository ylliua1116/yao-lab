# Contributing / 贡献指南

Thanks for your interest in YAO LAB. Suggestions, bug reports, accessibility improvements, and properly sourced Zhouyi text corrections are welcome through GitHub Issues or Pull Requests.

## Before proposing source changes

- Read [LICENSE](LICENSE) (PolyForm Shield 1.0.0), [NOTICE](NOTICE), [RIGHTS_MAP.md](RIGHTS_MAP.md), and [BRAND_POLICY.md](BRAND_POLICY.md).
- Identify your own contribution and its provenance. Only submit work you can lawfully contribute; preserve third-party notices.
- For textual corrections include the hexagram name/number, line index, the current text, proposed text, source edition and bibliographic or stable URL reference. Textual data follows its independent licensing path.
- Contributions are reviewed before merging. A pull request does **not** automatically transfer your copyright to the maintainer or authorize relicensing on your behalf; separate written permission may be required for future licensing arrangements.
